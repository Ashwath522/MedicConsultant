# 4. Architecture and Tech Stack

## 4.1 System architecture

```
┌──────────────────────────────────────────────┐
│  Frontend: React + Ionic (iOS style)         │
│  Web app → installable (Safari) → iOS app    │
│  (Capacitor)                                 │
└───────────────────────┬──────────────────────┘
                        │ HTTPS / REST
┌───────────────────────▼──────────────────────┐
│  Backend: FastAPI (Python)                   │
│  Auth · Episodes · Orchestration · Audit     │
└───┬──────────┬──────────┬──────────┬─────────┘
    │          │          │          │
┌───▼───┐ ┌────▼────┐ ┌───▼───┐ ┌────▼─────┐
│Speech │ │Extract  │ │ OCR   │ │ Matcher  │
│faster-│ │LLM →    │ │Gemini │ │RapidFuzz │
│whisper│ │JSON     │ │Vision/│ │+ medicine│
│+ time-│ │(summary,│ │Paddle │ │database  │
│stamps │ │meds,    │ │OCR    │ │+ confid- │
│       │ │reminders│ │       │ │ence      │
└───┬───┘ └────┬────┘ └───┬───┘ └────┬─────┘
    └──────────┴─────┬────┴──────────┘
              ┌──────▼──────┐
              │ Rules engine│  deterministic: allergy, interaction,
              │             │  max dose, mismatch, duplicate
              └──────┬──────┘
              ┌──────▼──────┐
              │ User confirm│  nothing goes live without this
              └──────┬──────┘
              ┌──────▼──────┐
              │ Care plan + │
              │ notifications│
              └─────────────┘
         PostgreSQL / Supabase (all data)
```

**Key principle:** keep every AI provider behind a single interface (for example `llm.extract()` or `ocr.read()`), so Gemini can be swapped for Ollama, or PaddleOCR for Gemini Vision, without touching the rest of the code.

## 4.2 Free tech stack (₹0)

| Layer | Choice | Free option / notes |
|---|---|---|
| Frontend | React + Vite | Open source |
| UI | Ionic React (`mode: 'ios'`) | Native-looking iOS components |
| Installable web app | vite-plugin-pwa | Add to Home Screen + Web Push |
| Native wrapper | Capacitor (iOS) | Free; needs Xcode on the Mac |
| Backend | FastAPI | Open source |
| Database + auth | Supabase free tier, or local PostgreSQL | Supabase includes login |
| Speech to text | faster-whisper (small/medium) on the laptop | Google Colab free GPU for bigger models; test IndicWhisper too |
| LLM | Gemini API free tier, **or** Ollama (Llama 3.1 8B / Qwen 2.5 7B) locally | Ollama is fully private |
| Prescription OCR | Gemini Vision free tier, **or** PaddleOCR / TrOCR locally | Gemini is better at handwriting |
| Fuzzy matching | RapidFuzz | Python library |
| Medicine data | Kaggle Indian medicine dataset (brand → generic) | Free |
| Interactions | DDInter | Free for academic use |
| Notifications | Capacitor Local Notifications (iOS app), Web Push (installable web app) | Both free |
| Calls | `tel:` links | Uses the phone's own calling |
| Family sharing | WhatsApp click-to-send link | Free (avoid paid SMS APIs) |
| Hosting | Laptop for the demo; Render free tier or Oracle Cloud Always Free | Render's free servers sleep when idle |
| Code | GitHub (+ Student Developer Pack) | Free |

## 4.3 Two ways to run the AI

| | Option A: fully local | Option B: hybrid (recommended) |
|---|---|---|
| Speech | faster-whisper (local) | faster-whisper (local) |
| LLM | Ollama | Gemini free tier |
| OCR | PaddleOCR / TrOCR | Gemini Vision |
| Cost | ₹0, no limits | ₹0, with rate limits |
| Privacy | Excellent | Mock or de-identified data only |
| Needs | 16 GB RAM, ideally a GPU | Any laptop |

## 4.5 Main API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/auth/signup`, `/auth/login` | Accounts |
| GET/PUT | `/profile` | Profile, allergies, routine |
| CRUD | `/contacts` | Family and doctor |
| POST | `/episodes` | Create an episode (AI suggests the category) |
| GET | `/episodes`, `/episodes/{id}` | List and view |
| POST | `/episodes/{id}/consultation` | Upload audio → transcript + summary + extracted items |
| POST | `/episodes/{id}/prescription` | Upload image → OCR + matched medicines |
| POST | `/episodes/{id}/verify` | Run the rules engine → warnings |
| POST | `/items/confirm` | User confirms extracted items |
| POST | `/episodes/{id}/careplan` | Generate the schedule |
| CRUD | `/reminders` | Status: taken / snoozed / skipped |
| POST | `/checkins` | Symptoms + sleep |
| GET | `/episodes/{id}/timeline` | Recovery timeline |
| PATCH | `/episodes/{id}/close` | Close the episode |
